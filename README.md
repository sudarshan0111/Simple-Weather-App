# Simple Weather App

## Project Overview

This project is a responsive weather application that provides real-time weather information for any city using the OpenWeather API. It allows users to search for weather conditions and view temperature updates through a clean and user-friendly interface.

## Features

* City-based weather search
* Real-time temperature updates
* Weather condition display
* Responsive design
* Clean and modern UI

## Tools & Technologies Used

* HTML
* CSS
* JavaScript
* OpenWeather API

## Functionalities

1. Search weather by city
2. Display current temperature
3. Show weather conditions
4. Dynamic weather updates
5. Responsive user interface

## Learning Outcomes

* API Integration
* Fetch API usage
* JSON data handling
* DOM Manipulation
* Responsive Web Design
